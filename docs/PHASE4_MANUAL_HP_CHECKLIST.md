# Checklist Manual Phase 4 (Windows + HP)

- [ ] Laptop Windows 10/11 x64 menjalankan aplikasi tanpa error.
- [ ] Laptop dan HP terhubung ke Wi-Fi lokal yang sama.
- [ ] QR setiap slot dipindai; URL membuka portal slot yang benar.
- [ ] Portal terbuka dari HP tanpa internet/cloud.
- [ ] URL RTMP dapat disalin atau dipilih manual.
- [ ] Token invalid dan token expired ditolak dengan respons netral.
- [ ] Dialog Diagnostik menampilkan engine, checksum, port, adapter/IP, firewall, publisher, dan RTSP probe.
- [ ] Refresh diagnostics memperbarui hasil aktual.
- [ ] Preview support bundle tidak menampilkan stream key/token/clipboard/data pribadi.
- [ ] Support bundle berhasil diekspor dan file dapat dibaca.
- [ ] Firewall inspection bersifat read-only.
- [ ] Firewall repair hanya membuat rule aplikasi pada profile Private.
- [ ] Penolakan UAC menampilkan fallback manual yang jelas.
- [ ] Tidak ada tag atau release dibuat selama validasi.
